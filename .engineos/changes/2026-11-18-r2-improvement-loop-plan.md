# R2 plan: the improvement loop (SPEC 0003)

## What
Planning only. This change writes SPEC 0003 for the first part of R2 (PRD 0001 section 3 R2, section 8 steps 2, 4, 5 and 6, AC 31, 32, 34, 35, 36), plus ADR 0004 for the local embedding runtime. It writes no code.

## Why
R1 records outcomes but does nothing with them. R2 closes the loop: it ranks asset versions by outcome, finds assets by meaning, compares versions A and B, and saves learnings back to the catalog, while promotion stays an owner decision.

Risk is high for these reasons:
- a new model runtime runs inside the api and watcher;
- catalog text is embedded, and D10 requires that it never leaves the Mac;
- A/B comparison doubles the spend of each run it covers.

## Out of this change
- **Curator agent (AC 33):** needs the 12-step topology interview and the owner's `topology-approval` before any code; that work becomes a later SPEC.
- **Cloud video-generation and avatar providers:** need a provider ADR first.
- **R1-FP:** stays deferred. R2 is planned on R1 and rev 4 code that has not been compiled yet.
